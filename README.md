# zoolomino-site

Zoolomino 앱의 공개 페이지. GitHub Pages로 호스팅한다.

- `index.html` — 소개 및 지원 페이지 (스토어의 **지원 URL**)
- `privacy.html` — 개인정보처리방침 (스토어의 **개인정보처리방침 URL**, 필수)

## 배포

저장소 Settings → Pages → Source를 `main` 브랜치 `/ (root)`로 설정하면 끝.
몇 분 뒤 `https://<사용자명>.github.io/zoolomino-site/` 에서 열린다.

## 주의

- 이 저장소는 **공개**여야 한다. GitHub Pages는 비공개 저장소에서 유료 플랜이 필요하다.
- 앱 소스는 별도의 비공개 저장소에 둔다.
- 앱 안의 방침 내용을 고치면 `privacy.html`도 같이 고쳐야 한다. 두 곳이 어긋나면 심사에서 문제가 된다.
